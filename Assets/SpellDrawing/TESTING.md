# SpellDrawing 테스트

## 1. 단위 테스트
Test Runner(EditMode)에서 `VoxelMagic.SpellDrawing.Tests` 실행.

| 테스트 | 확인 내용 |
|---|---|
| `StrokeRecorderTests` | 간격 기록, 끝점 보존, 영역 밖 시작 무시, 경계 잘라내기, 여러 획 |
| `StrokeResamplerTests` | 항상 N개, 등간격, 점만 찍은 입력, 정규화 후 위치·크기 제거 |
| `ChamferSimilarityMetricTests` | 두 점수 방식 각각: 같은 모양 ≈1, 이동·크기, 거꾸로·획 나누기, 흔들림, 절반, 직선·낙서, 빈 그림, 순서, 계산 시간 |
| `DrawingSessionTests` | 카운트다운→그리기→결과, 빈 그림 기록, 취소 |
| `StrokeRasterizerTests` | 선 픽셀 칠하기 |

## 2. 기준 비교표
`SimilarityBaselineTests.PrintBaselineTable` 실행 결과 (N=64, 허용 거리 0.08).
- **평균거리**: 평균 거리 ÷ 허용 거리 (지침 방식, 기본값)
- **점별**: 점마다 거리 ÷ 허용 거리를 0~1로 자른 뒤 평균

### 2026-10-30 1차 결과 (원본 도안: 원 안 삼각형)
"유사도·커버리지·정밀도"는 정규화 점수, "비정규화"는 가이드 좌표 그대로 비교한 유사도.

| 경우 | 평균거리: 유사도 | 커버리지 | 정밀도 | 비정규화 | 점별: 유사도 | 커버리지 | 정밀도 | 비정규화 |

계산 시간: 판정 1회 평균 2.4~2.9 ms (점 64개, 에디터).

관찰
- **정규화는 일부만 그린 그림에 불리하다.** 절반만 그리면 무게중심·크기가 원본과 달라져서, 정규화 과정에서 그림이 엉뚱한 곳으로 늘어난다 (절반: 정규화 0.20 / 비정규화 0.42).
- 평균거리 + 정규화 조합은 **절반(0.20) < 낙서(0.30)** 로 순서가 뒤집힌다.
- 평균거리 + 비정규화 조합은 완벽 1.00 > 약간 흔들림 0.95 > 많이 흔들림 0.88 > 원만 0.47 > 절반 0.42 > 낙서 0.30 > 직선 0.00 으로 **사람 기대 순서와 맞는다.**
- 점별 방식은 전체적으로 후하다 (낙서 0.42~0.44, 절반 비정규화 0.73).
- 비정규화는 위치·크기 차이에 엄격하다 (0.05 옮김 → 0.57, 0.7배 → 0.00). 가이드를 따라 그리는 1단계에서는 오히려 맞는 동작일 수 있다.

**결정 (2026-10-30)**: 주 점수 = 평균거리 + 비정규화. 순서 테스트(`OrderMatchesHumanExpectation`, `UnrelatedShapesScoreClearlyLow`)는 이 방식에만 적용하고, 점별 방식에서는 건너뛴다(Inconclusive).

## 3. 사람 테스트
### 방법
1. `Assets/SpellDrawing/Scenes/DrawingTest.unity`를 열고 Play. 게임 뷰는 16:9 권장 (다른 비율도 전체가 보이게 맞춰짐).
2. Space(또는 시작 버튼) → 3, 2, 1 → 8초 동안 가이드 위에 마우스 왼쪽 버튼으로 그린다. Esc는 취소.
3. 결과 패널의 점수, 겹쳐 보기(빨강 = 빠뜨림, 주황 = 삐져나옴)를 보고, **내가 느낀 점수**를 0~1로 적는다.
4. 같은 방식으로 10회 이상: 꼼꼼히 / 대충 / 일부러 절반만 / 일부러 크게·작게·옮겨서 / 낙서.
5. 필요하면 허용 거리 슬라이더를 바꿔 다시 비교한다 (다음 시도부터 반영).
6. "로그 폴더 열기"로 `attempts.csv`와 PNG를 확인한다.
